# Data

This folder holds the FileFragment500 data set, which is published separately ((https://doi.org/10.5281/zenodo.23936675)). Install it from the
repository root with

```
python tools/install_dataset.py path/to/FileFragment500_v1.0.zip
python tools/retrieve_napierone.py
```

and continue with section 1 of the main README. Apart from this file, the contents of this folder are not tracked by
git.

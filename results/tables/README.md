# Result tables

Generated by `python scripts/70_tables.py` from saved outputs.

- `T01_dataset`: Replacement collection: files and retained fragments by extension group and partition (from data/manifests/source_manifest.csv, data/fragments/*_fragments.csv)
- `T02_pairs`: Sampled pairs (four modes, 25% each) (from data/pairs/pair_summary.json)
- `T03_learnability`: Component learnability (seed 42) and derived weights (from runs/comp_*/summary_val.json, results/local/regression/comp_*.json, runs/learnability_weights.json)
- `T04_regression`: Agreement with each scheme's own composite target (test pairs) (from results/local/regression/<run>.json)
- `T04b_regression_three_seeds`: Additional robustness analysis: all schemes with seeds 42, 43, 44 (from results/local/regression/<run>.json)
- `T05_regression_by_mode`: Regression by pair-sampling mode and by actual provenance relation (from results/local/regression/<run>.json)
- `T06_provenance`: Provenance tasks on the test pool (from results/local/provenance/test__*.json, results/bootstrap/local_summary.json)
- `T06b_provenance_rankings`: Ranking metrics (Hit@1/5/10, MRR) and chance levels (from results/local/provenance/test__*.json)
- `T07_paired_differences`: Paired bootstrap differences against histogram cosine (same file draws) (from results/bootstrap/local_summary.json)
- `T08_jpg_jpeg_sensitivity`: Sensitivity analysis: JPG and JPEG merged into one extension group (from results/local/provenance/test__*.json)
- `T09_fp32_sensitivity`: Sensitivity of provenance results to float16 score quantisation (from results/local/provenance/test__*.json, results/local/provenance/fp32__*.json)
- `T06c_by_extension_group`: Retrieval and adjacency by recorded extension group (test pool) (from results/local/per_query/test__*.csv)
- `T10_shortlist_effort`: Learned shortlist + histogram re-ranking versus direct ranking (examiner effort) (from results/local/shortlist.json, results/local/per_query/shortlist__*.csv)
- `T11_reconstruction`: Greedy chaining on consecutive held-out blocks (adjacency recovery) (from results/local/reconstruction/*.json, results/bootstrap/recon_summary.json)
- `T12_ablation`: Component removal and subset targets (seed 42) (from results/local/regression/*.json, results/local/provenance/test__*.json)
- `T13_loto_heic`: Leave-one-type-out: HEIC removed from training and validation pairs (from results/local/loto_heic.json, results/local/regression/*.json)
- `T14_govdocs_aligned`: Govdocs1 external test set, aligned 512-byte runs (no retraining) (from results/govdocs1/aligned__*.json, results/bootstrap/govdocs_summary.json)
- `T15_govdocs_conditions`: Govdocs1 under alignment, encryption, compression and 4096-byte blocks (from results/govdocs1/*.json, data/govdocs1/build_report.json)
- `T16_cost`: Measured inference and ranking cost (from results/local/cost.json)
- `T12b_ablation_paired_differences`: Ablation and subset models minus the all-six heuristic model, paired bootstrap (added after the freeze; written by scripts/61_ablation_paired.py) (from results/bootstrap/local__*.npz, results/bootstrap/local_paired_vs_heuristic_s42.json)
